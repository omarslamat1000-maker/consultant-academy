# دليل ربط Google Gemini

## الحصول على مفتاح
1. افتح [Google AI Studio](https://aistudio.google.com/) → **Get API key** → أنشئ مفتاحًا.
2. لا تشارك المفتاح ولا تضعه في الكود أو Git.

## طريقتان للربط

### (أ) من داخل التطبيق — الموصى بها
1. اضبط على Netlify متغير `CONFIG_ENCRYPTION_KEY` (32 بايت base64):
   ```bash
   node -e "console.log(require('crypto').randomBytes(32).toString('base64'))"
   ```
2. بحساب مسؤول: **لوحة المسؤول → مزود الذكاء الاصطناعي** → أدخل المفتاح والنموذج ودرجة الإبداع والحد الأقصى → **اختبار الاتصال** → **حفظ آمن**.
3. يُرسل المفتاح مرة واحدة عبر HTTPS إلى `/api/ai-provider/save`، يُشفَّر AES-256-GCM ويُخزَّن في `academy.ai_providers`، ولا يعود إلى المتصفح.

### (ب) متغير بيئة خادمي
اضبط `GEMINI_API_KEY` (واختياريًا `GEMINI_MODEL`) في Netlify. يُستخدم كبديل تلقائي عندما لا يوجد مزود نشط محفوظ في التطبيق.

## النماذج المدعومة
`gemini-2.5-flash` (افتراضي، توازن جودة/تكلفة)، `gemini-2.5-pro` (أعلى جودة للحالات المتقدمة)، `gemini-2.5-flash-lite`، `gemini-2.0-flash`.

## كيف يُستخدم Gemini
| الاستخدام | القالب | الإخراج |
| --- | --- | --- |
| توليد الحالات | `case-generator-system-prompt` | JSON مطابق لـ `CASE_RESPONSE_SCHEMA` ثم تحقق Zod |
| تقييم الإجابات | `case-evaluator-system-prompt` | درجات 7 أبعاد + تغذية راجعة؛ الدرجة الكلية تُحسب خادميًا بالأوزان |
| أسئلة المتابعة | `follow-up-interviewer-prompt` | سؤال واحد لكل دور مع تقييم موجز |
| الخطة الأسبوعية | `adaptive-recommendation-prompt` | خطة 6 أيام (القرار الأساسي حتمي خادميًا) |

## طبقة الجودة
- System Instructions قوية + Few-Shot (مثال قوي/ضعيف) + Rubric ثابت + Structured Output.
- تحقق JSON: إصلاح مرة واحدة → إعادة توليد مرة واحدة → رسالة خطأ واضحة وتسجيل بلا أسرار.
- منع التكرار: بصمة + توقيع دلالي + مقارنة مع آخر 100 حالة + إعادة توليد تلقائية (حتى 3 محاولات).
- Prompt Versioning: كل حالة وتقييم يحمل إصدار القالب؛ يمكن إنشاء إصدارات مخصصة وتفعيلها من لوحة المسؤول.
- القياس (لوحة الإحصاءات): نسبة JSON الصالح، نسبة الإصلاح، نسبة الحالات المرفوضة للتكرار، زمن الاستجابة، الانحراف بين التقييم الآلي والبشري (عبر التقييم البشري للمحاولات في مراجعة الحالات).
- لا Fine-tuning في المرحلة الأولى؛ البنية (حالات مرجعية معتمدة + تقييم بشري + إصدارات) تسمح بإضافته لاحقًا.

## استكشاف الأخطاء
| الرسالة | السبب | الحل |
| --- | --- | --- |
| مفتاح API غير صالح | مفتاح خاطئ أو منتهٍ | أعد إنشاء المفتاح واستخدم "تدوير المفتاح" |
| النموذج غير متاح لهذا المفتاح | اسم نموذج غير مدعوم في حسابك | اختر `gemini-2.5-flash` |
| تجاوز حصة الاستخدام | حد المزود | انتظر أو فعّل الفوترة في Google |
| مفتاح التشفير الرئيس غير مضبوط | `CONFIG_ENCRYPTION_KEY` غائب | اضبطه في Netlify أو استخدم `GEMINI_API_KEY` |
| تعذر فك تشفير المفتاح المحفوظ | تغيّر `CONFIG_ENCRYPTION_KEY` | أعد إدخال المفتاح (تدوير) |
