# تقرير التعديلات والوظائف

## نتيجة التدقيق الأولي
مجلد `Consultant Academy` كان **فارغًا تمامًا** (لا كود، لا `package.json`، لا Git). لذلك بُنيت المنصة من الصفر، مع الالتزام الكامل بالمواصفة. المشروع القائم في Supabase (`kqihinsdxufwwzwylpwa`) مشترك مع تطبيق آخر (`public.profiles`, `public.audit_logs`…)، فوُضعت جميع جداول الأكاديمية في مخطط مستقل **`academy`** لتجنب أي تعارض (قرار معماري موثق).

## الافتراضات الموثقة
| الافتراض | السبب |
| --- | --- |
| المخطط `academy` بدل `public` | مشروع Supabase مشترك مع تطبيق آخر يملك `profiles` و`audit_logs` |
| `generated_cases.created_at` بدل `created_at_at` الوارد في المواصفة | خطأ مطبعي واضح |
| جدول إضافي `quiz_attempts` | قاعدة "70% في ثلاثة اختبارات" تحتاج سجل محاولة لكل اختبار (وليس أفضل نتيجة فقط) |
| جداول إضافية `case_followups`, `prompt_templates`, `ai_metrics`, `rate_limits` | أسئلة المتابعة، إصدارات Prompts، قياس الجودة، حدود المعدل عديمة الحالة |
| المستوى المطلوب في المحاكاة يُقصّ خادميًا إلى مستوى المستخدم + درجة واحدة | "لا تثق بالمستوى المرسل من الواجهة" مع السماح بتحدٍ محدود |
| التصحيح الحتمي للاختبارات والحالة التطبيقية خادمي (`/api/quiz/submit`) والمتدرب يرى `question_bank_public` بلا إجابات | منع الغش والاعتماد على الخادم |
| ai_providers في المخطط نفسه مع منع كامل لـ anon/authenticated (بلا امتيازات ولا سياسات) | Data API يخدم المخططات المكشوفة فقط؛ الحماية بالامتيازات + RLS + التشفير |
| Netlify Functions تُعرّف مساراتها عبر `config.path` (v2) | المطلوب `export default async (req, context)` |

## ما أُنجز (قائمة الوظائف)
### الأساس الأمني
- Supabase Auth (تسجيل، دخول، استعادة كلمة مرور، تأكيد بريد، رسائل خطأ عربية).
- 6 ترحيلات SQL (مخطط، منهج، حالات، ذكاء/تدقيق/معدل، RLS، تعبئة) — مطبّقة على المشروع.
- أدوار من جدول محمي + `is_admin()` مقيّدة، مشغّل إنشاء الملف، حماية حقل المستوى.
- RLS على كل الجداول؛ `anon` بلا وصول؛ كتابة الجداول التقييمية خادمية فقط.
- تشفير AES-256-GCM لمفاتيح المزودين + تدقيق بلا أسرار + إخفاء الأنماط في السجلات.
- تحقق Zod، حدود حجم، حدود معدل (قاعدة بيانات)، مهلات، CORS اختياري، ترويسات أمان.

### المنهج التدريبي
- 12 وحدة كاملة البنية (هدف، شرح، مصطلحات، خطوات، 3 أمثلة، أخطاء، قائمة تحقق، تمرين، اختبار، حالة تطبيقية، تفسير نتيجة، توصية، شرط إكمال) و73 سؤالًا تغطي 15 نوعًا.
- صفحة الوحدة بتبويبات، مصحّح لجميع الأنواع، حفظ التقدم وأفضل نتيجة وعدد المحاولات.

### الذكاء الاصطناعي
- محوّل مزود (Gemini REST بإخراج مهيكل) + حل الإعدادات (قاعدة بيانات مشفّرة ← متغير بيئة).
- توليد الحالات: 22 حقلًا بما فيها البيانات المخفية، الحسابات، Rubric خاص، أسئلة المحاور.
- منع التكرار: بصمة + توقيع دلالي + تشابه موزون + مقارنة آخر 100 حالة + إعادة توليد (3 محاولات) + حفظ المرفوض للقياس + إعادة صريحة فقط.
- التقييم: 7 أبعاد بأوزان المواصفة، الدرجة الكلية خادميًا، 14 مخرجًا (قوة، أخطاء، فجوات، حسابات، افتراضات، خروج عن السؤال، MECE، وضوح، معيارية، محسّنة، تمرين، الحالة التالية).
- المتابعة (Interviewer-Led) حتى 6 أدوار بضغط متدرج.
- إصلاح JSON مرة ← إعادة توليد مرة ← خطأ واضح؛ Prompt Versioning؛ مقاييس الجودة.
- 5 قوالب Prompts مُصدَّرة قابلة للتعديل والتفعيل من لوحة الإدارة.

### التعلم التكيفي
- Mastery Score متحرك (EWMA)، اكتشاف التراجع، قواعد انتقال صارمة (وحدات + 3 اختبارات + 3 حالات غير مكررة + حد أدنى للمهارات)، ترقية خادمية فقط، توصية تالية حتمية، خطة أسبوعية (ذكاء اصطناعي أو قاعدية).

### الواجهات
- تسجيل الدخول، لوحة التقدم، المسار، الوحدة، محاكاة الحالة (عرض تدريجي، بيانات عند الطلب، مؤقت، تحدي 60/90، حوار محاور)، السجل (بحث/تصفية/إعادة)، ملف الإتقان، الملف الشخصي.
- لوحة المسؤول: إحصاءات، مستخدمون، وحدات، بنك أسئلة، مراجعة حالات + تقييم بشري، Prompts، مزود الذكاء الاصطناعي (إضافة/اختبار/تدوير/تعطيل/حذف)، سجل العمليات.
- RTL، هوية خضراء/ذهبية، 16px، تباين، لوحة مفاتيح، Labels، حالات Loading/Empty/Error/Success، متجاوب.

### الوضع التجريبي
- بلا Supabase: حساب محلي، المنهج كاملًا، 6 حالات ثابتة، تقييم محلي حتمي موسوم، حفظ في المتصفح، إشعار دائم.

### الاختبارات والأدوات
- 82 اختبارًا (وحدة/تكامل/أمان) — انظر `TEST_RESULTS.md`.
- `tools/dev-api.ts` (محاكاة Netlify محليًا)، `check-secrets.mjs`، `gen-seed-sql.ts`، `seed-curriculum.ts`.

## التحديث الثاني (2026-09-14): الإصلاحات والتحسينات
- **مرونة الواجهة**: لوحة التقدم وملف الإتقان يحسبان التوصية والإحصاءات محليًا عبر Data API عند تعذر الوصول إلى Netlify Functions (بلا ترقية مستوى ولا خطة ذكية، مع إشعار واضح). لم تعد الصفحة الرئيسة تفشل عند غياب `SUPABASE_SERVICE_ROLE_KEY` محليًا.
- **صفحة مفتاح API**: قائمة جاهزية الربط (وظائف، قاعدة بيانات، مفتاح تشفير، مزود نشط) مع تلميح إصلاح لكل بند، خطوات الإضافة، إظهار/إخفاء المفتاح، تحقق من الصيغة، ورابط مباشر في الشريط الجانبي للمسؤول. `/api/health` يعيد `encryption_ready`.
- **لوحة المسؤول**: تنبيه تلقائي بحالة الوظائف الخادمية واتصالها بقاعدة البيانات.
- **أداة `npm run doctor`**: جدول جاهزية متغيرات البيئة مع كشف الأخطاء الشائعة (وضع مفتاح سري في الواجهة، مفتاح تشفير بطول خاطئ).
- **الهوية البصرية**: علامة "شجرة القضايا" (SVG يُرسم ذاتيًا، يحترم تقليل الحركة)، عناوين بخط Amiri، نحاس مطفأ بدل الذهبي الساطع، صفحة دخول مقسومة بأطروحة المنصة وأرقامها، بطاقة توجيه للتوصية التالية مع حلقة جاهزية المستوى، ختم الدرجة في نتيجة الحالة، إصلاح تخطيط الجوال وزر خروج في التنقل.
- **GitHub**: مستودع محلي على فرع `main` مع CI (`.github/workflows/ci.yml`) و`.gitattributes`؛ النشر يتطلب `gh auth login` من صاحب الحساب (انظر README).
