# دليل استخدام المسؤول

الوصول: تسجيل الدخول بحساب دوره `admin` → رابط **لوحة المسؤول** في الشريط الجانبي.

## الإحصاءات
المستخدمون، المحاولات ومتوسط الدرجات (30 يومًا)، الحالات المولدة والمرفوضة للتكرار والمنتظرة للمراجعة، جودة الذكاء الاصطناعي (نسبة JSON الصالح، الإصلاح، التكرار، زمن الاستجابة)، الانحراف الآلي/البشري، مقارنة إصدارات Prompt، وتقارير الأخطاء الأخيرة.

## المستخدمون
قائمة المستخدمين مع الدور والمستوى وعدد المحاولات والمتوسط. يمكنك تغيير الدور (متدرب/مسؤول) والمستوى يدويًا عند الحاجة (كل تغيير يُسجَّل في سجل العمليات). لا يمكنك إزالة صلاحية المسؤول عن حسابك.

## الوحدات
إضافة/تعديل/حذف الوحدات: العنوان، المعرّف، المستوى، الترتيب، الوصف، النشر، ومحتوى الوحدة بصيغة JSON (الحقول المطلوبة موضحة في الشاشة: الهدف، الشرح، المصطلحات، الخطوات، الأمثلة الثلاثة، الأخطاء، قائمة التحقق، التمرين، الحالة التطبيقية، تفسير النتيجة، التوصية التالية، شرط الإكمال، المهارة الرئيسة).

## بنك الأسئلة
اختر الوحدة ثم أضف/عدّل الأسئلة: النوع (15 نوعًا)، المهارة، المستوى، النص، الخيارات (JSON)، الإجابة الصحيحة (JSON)، الشرح، النشر. التصحيح خادمي؛ المتدرب لا يرى الإجابات.

## مراجعة الحالات المولدة
الحالات المولدة بالذكاء الاصطناعي تظهر "بانتظار المراجعة". اعرض المحتوى الكامل واعتمد/ارفض، أو اعتمد كمثال مرجعي. أدخل **تقييمًا بشريًا** للمحاولات لقياس الانحراف عن التقييم الآلي (يظهر في الإحصاءات).

## Prompts
القوالب المضمَّنة (5) للقراءة مع رقم الإصدار. يمكنك إنشاء إصدار مخصص (انسخ من المضمَّن أو من إصدار سابق)، ثم **تفعيله** ليستخدمه الخادم فورًا. كل حالة/تقييم يحمل رقم الإصدار المستخدم لمقارنة الجودة بين الإصدارات. حافظ على المتغيرات `{{...}}`.

## مزود الذكاء الاصطناعي
انظر [إدارة مفاتيح API](API_KEY_MANAGEMENT.md).

## سجل العمليات
آخر 200 عملية (حفظ/اختبار/تدوير/تعطيل مفاتيح، تغيير أدوار، اعتماد حالات، ترقيات مستوى، تقييمات…) بلا أي أسرار.

## قواعد تشغيلية
- الوضع التجريبي لا يتيح لوحة المسؤول (لا Supabase).
- عند عدم ربط مزود ذكاء اصطناعي، يعمل النظام بحالات ثابتة وتقييم محلي حتمي مع وسم واضح للمتدرب.
- الترقية بين المستويات آلية وفق القواعد (وحدات المستوى + 3 اختبارات ≥70 + 3 حالات غير مكررة ≥70 + حد أدنى للمهارات الرئيسة)؛ التعديل اليدوي متاح للمسؤول للحالات الاستثنائية.
