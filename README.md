# أكاديمية المستشار

منصة عربية ذكية (RTL) لتطوير مهارات حل المشكلات والحالات الاستشارية، من المبتدئ إلى الخبير المتقدم، بمنهج من 12 وحدة ومحرك حالات ذكي (Gemini) وتقييم وفق Rubric من 100 درجة وتعلم تكيفي.

## البنية التقنية

| الطبقة | التقنية |
| --- | --- |
| الواجهة | React 19 + TypeScript + Vite (RTL، تصميم حكومي تنفيذي، متجاوب) |
| قاعدة البيانات والمصادقة | Supabase (Postgres + Auth + RLS) — مخطط مستقل `academy` |
| الوظائف الخادمية | Netlify Functions v2 (`export default async (req) => …`) |
| الذكاء الاصطناعي | Google Gemini عبر REST بإخراج مهيكل (JSON Schema)، عبر محوّل مزود قابل للتوسعة |
| الاختبارات | Vitest (وحدة + تكامل بعميل وهمي + أمان) |

## هيكل الملفات

```
├─ src/                    واجهة React (صفحات، مكونات، طبقة بيانات موحدة، سياق المصادقة)
├─ shared/                 كود مشترك: الأنواع، Rubric، Mastery، البصمة ومنع التكرار، قواعد المستويات،
│  ├─ curriculum/          المنهج المضمَّن (12 وحدة + 73 سؤالًا)
│  ├─ prompts/             قوالب Prompts مُصدَّرة (5 قوالب)
│  ├─ gemini-schemas.ts    مخططات الإخراج المهيكل
│  └─ schemas.ts           مخططات التحقق (Zod)
├─ server/                 منطق الوظائف الخادمية (مصادقة، تشفير، مزودون، حالات، تقييم، توصيات، إدارة)
├─ netlify/functions/      17 وظيفة رقيقة تُعرِّف المسارات /api/*
├─ supabase/migrations/    6 ترحيلات (المخطط، المنهج، الحالات، الذكاء، RLS، التعبئة)
├─ tests/                  unit / integration / security
├─ tools/                  خادم API تطويري، فحص الأسرار، توليد ترحيل التعبئة، تعبئة عبر Data API
└─ docs/                   أدلة الإعداد والنشر والاستخدام والتقارير
```

## التشغيل المحلي السريع

```bash
npm install
cp .env.example .env      # عبّئ القيم (بلا أسرار في Git)
npm run dev               # الواجهة على http://localhost:8220
npm run dev:api           # خادم API يحاكي Netlify Functions على 8788 (نافذة ثانية)
```

بدون متغيرات `VITE_SUPABASE_*` تعمل الواجهة في **الوضع التجريبي** (دروس وحالات ثابتة، تقييم محلي مبسّط، حفظ في المتصفح) مع إشعار واضح.

## الأوامر

| الأمر | الوظيفة |
| --- | --- |
| `npm run build` | فحص الأنواع (واجهة + وظائف) ثم بناء Vite |
| `npm test` | جميع الاختبارات |
| `npm run check:secrets` | فحص المستودع وحزمة البناء من الأسرار |
| `node tools/gen-seed-sql.ts` | إعادة توليد `0006_seed_curriculum.sql` من المنهج المضمَّن |
| `node tools/seed-curriculum.ts` | تعبئة المنهج عبر Data API بحساب مسؤول (بديل عن SQL) |

## مبادئ الأمان المطبقة

- لا مفاتيح في الواجهة: كل استدعاءات Gemini تمر عبر Netlify Functions، و`service_role` خادمي فقط.
- مفاتيح المزودين تُشفَّر بـ AES-256-GCM بمفتاح رئيس خادمي `CONFIG_ENCRYPTION_KEY`، ولا تُعاد إلى المتصفح أبدًا (آخر 4 أحرف فقط)، ولا تُسجَّل.
- الدور يُقرأ من جدول `academy.roles` المحمي (لا من `user_metadata`)، والمستوى لا يغيّره إلا الخادم.
- RLS على جميع الجداول؛ الكتابة على الجداول التقييمية خادمية فقط؛ `anon` بلا وصول.
- تحقق من المدخلات (Zod)، حدود حجم الطلب، حدود معدل مخزنة في قاعدة البيانات، مهلات، ورسائل خطأ آمنة.
- حواجز ضد حقن التعليمات في إجابات المتدربين، ولا تُمنح درجات لمجرد ذكر المصطلحات.
